# Security Policy

## Supported Versions
Only the latest release receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability
**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability or secret detection bypass:
1. Use GitHub's private vulnerability reporting feature on the repository.
2. Provide a clear description of the vulnerability, test scenario, and proof-of-concept.

Reports will be acknowledged within 48 hours and resolved promptly.
